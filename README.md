# Anavya E-Com

A Full Stack E-Commerce Web Application built using React.js, Java, Spring Boot and MySQL.

## Tech Stack
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- React.js
- JavaScript
- HTML, CSS, Bootstrap

## Planned Features

### User Module
- Product browsing
- Product details
- Search and filter
- Shopping cart

### Admin Module
- Add, update and delete products
- Manage product categories
- Product management
